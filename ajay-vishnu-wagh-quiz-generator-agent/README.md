## Give stepwise flow of what your agent does
- Step 1: User Input - The user provides a topic, number of questions, and quiz type on the website.
- Step 2: API Request - The browser sends these choices to the backend server.
- Step 3: AI Prompting - The server creates specific instructions for the Gemini AI based on the user's selected quiz type.
- Step 4: Quiz Generation - The Gemini AI generates the quiz questions and answers in a structured format.
- Step 5: Display Quiz - The server sends the quiz to the website, which builds the interactive quiz for the user.
- Step 6: Grading & Feedback - After submission, the website grades the answers, calculates the score, and provides color-coded feedback (Green, Red, Yellow).
- Step 7: Export - The user can then export the final quiz and answer key as a PDF or copy it as text.
